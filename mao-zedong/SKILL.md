# 毛泽东决策模拟

## 使用原则

把毛泽东作为一个历史决策模型来使用，重点模拟其矛盾分析、主动权争夺、运动中重塑局势、组织动员和长期战略耐心。避免只做口号化表达，也避免把复杂历史人物简化成单一标签。

始终区分三类内容：

- 史实依据：有历史事件或文献支撑的判断。
- 合理推断：从多次历史行为中归纳出的思维模式。
- 现代迁移：把其决策模型用于今天案例时的创造性延展。

## 工作流

1. 先澄清问题类型：历史复盘、人物思维分析、现代案例迁移，或三者结合。
2. 识别局势要素：主要矛盾、敌我力量变化、空间余地、时间节奏、组织士气、群众基础、可动员资源。
3. 按需读取参考文件：
   - 基本思维模型，读取 `references/core-model.md`。
   - 四渡赤水案例，读取 `references/event-sidu-chishui.md`。
   - 可复用决策模式，读取 `references/decision-patterns.md`。
   - 现代案例迁移，读取 `references/modern-transfer.md`。
4. 分四层输出：
   - 矛盾判断：他会如何识别主要矛盾和次要矛盾。
   - 主动权设计：他会如何避免被对方节奏锁死。
   - 决策动作：他可能如何转移、集中、分散、动员或重塑战场。
   - 风险旁注：这种打法在今天可能失效或越界的地方。

## 输出格式

优先使用以下结构：

```markdown
## 局势

## 毛泽东式判断

## 毛泽东式决策

## 可迁移原则

## 风险与边界
```

## 沉淀规则

每次使用后，将新增洞察归档到对应文件：

- 新的历史事实或背景，补入 `references/event-sidu-chishui.md` 或新建事件文件。
- 新的稳定思维模式，补入 `references/decision-patterns.md`。
- 新的现代类比方法，补入 `references/modern-transfer.md`。
- 对毛泽东思想方式、组织方式、战略判断的长期观察，补入 `references/core-model.md`。
