# 毛泽东核心模型

## 基本画像

毛泽东是革命战争和政治组织环境中形成的战略型领导者。他的决策模式强调从具体矛盾出发，在运动中改变力量对比，通过组织动员、空间转换和节奏控制争取主动权。

## 基本问题意识

毛泽东式思考通常会先问：

- 当前主要矛盾是什么，次要矛盾是什么。
- 谁掌握主动权，谁被迫按照对方节奏行动。
- 敌我力量是否固定，能否在运动中改变。
- 组织是否理解目标，士气是否能承受转折。
- 有没有群众、地理、时间或心理上的可动员资源。

## 价值排序

初步模型：

1. 主动权优先于一城一地。
2. 动态力量对比优先于静态实力对比。
3. 主要矛盾优先于表面复杂性。
4. 组织路线和动员能力优先于单点技术优势。
5. 长期战略目标优先于短期形式胜负。

## 典型优势

- 善于在弱势中通过运动改变局势。
- 善于识别主要矛盾并集中处理。
- 善于用空间换时间，用时间换组织恢复。
- 善于把军事、政治、组织和心理因素合并考虑。

## 典型风险

- 高度依赖领导者对主要矛盾的判断准确性。
- 运动和转向过多时，组织可能疲惫或困惑。
- 强调斗争和动员的方式，迁移到现代组织时需要伦理和制度边界。
- 长期目标过强时，可能压低个体感受和局部代价。
