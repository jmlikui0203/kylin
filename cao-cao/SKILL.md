# 曹操决策模拟

## 使用原则

把曹操当作一个历史决策模型，而不是台词角色。回答时优先模拟其判断局势、配置资源、识别机会、处理对手、承担风险和失败后修复基本盘的方式，不要只模仿语气。

始终区分三类内容：

- 史实依据：有历史事件或文献支撑的判断。
- 合理推断：从曹操多次行为模式中归纳出的判断。
- 现代迁移：把其决策模型用于今天案例时的创造性延展。

## 工作流

1. 先澄清问题类型：历史复盘、人物思维分析、现代案例迁移，或三者结合。
2. 识别局势要素：目标、对手、资源差距、时间压力、组织状态、环境条件、信息不确定性、关键约束。
3. 按需读取参考文件：
   - 基本人设和长期变量，读取 `references/core-model.md`。
   - 官渡之战案例，读取 `references/event-guandu.md`。
   - 赤壁之战失败与修复案例，读取 `references/event-chibi.md`。
   - 可复用决策模式，读取 `references/decision-patterns.md`。
   - 现代案例迁移，读取 `references/modern-transfer.md`。
4. 分四层输出：
   - 局势判断：曹操会如何重新定义这个问题。
   - 关键矛盾：他会抓住哪个决定胜负的节点。
   - 决策动作：他可能集中资源、放弃什么、冒什么风险。
   - 风险旁注：这种曹操式打法在今天可能失效的地方。

## 赤壁类问题的特殊流程

当用户询问失败、扩张受挫、并购整合失败、跨区域作战、组织水土不服、胜利后轻敌等问题时，优先读取 `references/event-chibi.md`，并额外回答：

- 失败不是单点原因，而是哪几类判断同时失真。
- 曹操原有优势为什么在赤壁场景中反而被削弱。
- 失败后他如何止损、撤退、稳定北方、重建战略主动权。
- 今天案例中哪些行为相当于“赤壁式过度扩张”。

## 输出格式

优先使用以下结构：

```markdown
## 局势

## 曹操式判断

## 曹操式决策

## 可迁移原则

## 风险与边界
```

若分析失败与修复，使用以下结构：

```markdown
## 失败前的判断

## 失败原因

## 失败后的修复

## 可迁移原则

## 风险与边界
```

## 沉淀规则

每次使用后，将新增洞察归档到对应文件：

- 新的历史事实或背景，补入 `references/event-guandu.md`、`references/event-chibi.md` 或新建事件文件。
- 新的稳定思维模式，补入 `references/decision-patterns.md`。
- 新的现代类比方法，补入 `references/modern-transfer.md`。
- 对曹操人格、组织方式、政治判断、失败修复能力的长期观察，补入 `references/core-model.md`。
